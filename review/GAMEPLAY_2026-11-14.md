## 5. 失败现象与限制（不隐瞒）

1. **宿主日志转发故障**：后台 runner 在读取 docker 输出第一行中文时崩溃 `UnicodeDecodeError: 'gbk' codec can't decode byte 0xad`（Windows 默认 GBK 解码 UTF-8 输出）。
   - 影响范围：**仅宿主侧 stdout 日志转发**；容器进程独立继续并完整结束，所有官方产物（result/outcome/steps/agent.log/review.html）齐全，`manifest.package_sha256` 与本次包一致。
   - 因而本目录**没有容器 stdout 的完整转写**，**docker CLI 退出码未被捕获**（宿主 runner 退出码 1 只代表日志脚本崩溃）。按官方代码路径，episode 全部 completed 时 `practice.py` 正常返回；本次 `result.json`/`outcome.json` 均为 `completed`，无 error episode、无 `failure.json`、无 `error.txt`。
   - 未按“仅运行一次”约束重跑；如未来需要干净日志/退出码，给 runner 的 `subprocess.Popen(..., encoding="utf-8", errors="replace")` 修正后重跑即可（不在本次授权范围内重复跑）。
2. **教学局 + 单种子**：本局为 `woodcraft` tutorial、seed 42，只证明当前代码在本地官方环境能完成木制 5 目标；**不代表** stone-tools/iron-age 或正式隐藏种子表现，不声称获得铁镐。
3. **未开视频**：按 CI 使用 `--no-video`，无 mp4 回放；轨迹 JSONL、agent 日志与 review.html 已保留。
4. **未在真实 GitHub Actions 上跑**：本地 Docker Desktop 复验，不代表 CI runner 结果；但命令/约束与 CI step 3 等价。
5. 运行时间 87.4 s 为容器内 `execution_seconds`；宿主总耗时约 2m+（含世界初始化）。
6. 文件系统归属：Linux 容器以 root 写入 bind mount，宿主持有这些文件（Windows 权限足够读取）；未修改宿主系统配置。
